# Open-source resources used

The datathon rules (rule 5) require links to every open-source library and framework used. Every component of
ReliefSync Z is open source or open data. No proprietary service or API is used.

## Libraries and frameworks

| Component | Used for | Licence | Link |
|---|---|---|---|
| scikit-learn | Model 1 Random Forest regressor, Model 2 Random Forest classifier, metrics | BSD-3-Clause | https://github.com/scikit-learn/scikit-learn |
| XGBoost | Model 1 benchmark regressor (second ML framework) | Apache-2.0 | https://github.com/dmlc/xgboost |
| llama.cpp | Local inference runtime for the Granite LLM (zDNN / NNPA backend on IBM Z) | MIT | https://github.com/ggml-org/llama.cpp |
| llama-cpp-python | Python bindings for llama.cpp | MIT | https://github.com/abetlen/llama-cpp-python |
| NetworkX | Road graph and shortest / safest route computation | BSD-3-Clause | https://github.com/networkx/networkx |
| NumPy | Numerical computing, synthetic data generation | BSD-3-Clause | https://github.com/numpy/numpy |
| pandas | Tabular data handling | BSD-3-Clause | https://github.com/pandas-dev/pandas |
| Matplotlib | Charts and route maps | Matplotlib licence (PSF-based, BSD-compatible) | https://github.com/matplotlib/matplotlib |
| joblib | Saving and loading scikit-learn models | BSD-3-Clause | https://github.com/joblib/joblib |
| Requests | Downloading the road network from the Overpass API | Apache-2.0 | https://github.com/psf/requests |
| JupyterLab | Notebook environment | BSD-3-Clause | https://github.com/jupyterlab/jupyterlab |
| Docker Engine (Moby) | Runs the LinuxONE Jupyter Lab ML container | Apache-2.0 | https://github.com/moby/moby |
